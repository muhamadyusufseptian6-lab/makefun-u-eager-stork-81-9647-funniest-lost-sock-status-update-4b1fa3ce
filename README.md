## The entry

A status update from the sock itself — the one that slipped under the fridge on laundry day and never came back:

> Day 47 under the fridge. The dust bunnies made me mayor. My partner filed a missing-sock report. I said nothing.

47 days, one promotion, zero apologies. The other sock is still out there doing press interviews.

## How it works

`main.ts` (Node 22, stdlib-only, deterministic) writes that single line to `$MAKEFUN_OUTPUT_DIR/entry.txt` — 112 characters, inside the 1–120 gate.

Run it locally:

```sh
MAKEFUN_OUTPUT_DIR=/tmp/lost-sock-out node main.ts
cat /tmp/lost-sock-out/entry.txt
```
